## 📌 Overview

This is a **Budget Management App** built using Python Object-Oriented Programming (OOP).  
It helps users manage different budget categories like Food, Clothing, and Auto, track expenses, and visualize spending in a text-based bar chart.

---

## 🚀 Features

- Create budget categories
- Deposit money with description
- Withdraw money with validation
- Transfer funds between categories
- Track balance automatically
- Generate spending percentage chart (ASCII bar chart)
